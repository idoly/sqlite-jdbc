= SQLite JDBC FFM

JDK 25+ 的 SQLite JDBC 4.3 驱动，使用 FFM 直接调用 SQLite，不使用 JNI。坐标：`io.github.idoly:sqlite-jdbc`。

== 构建

[source,shell]
----
mvn clean package
----

== 使用

[source,java]
----
import java.sql.DriverManager;

try (var connection = DriverManager.getConnection("jdbc:sqlite:sample.db");
     var statement = connection.createStatement()) {
    statement.executeUpdate("create table item(id integer primary key, value text)");
}
----

运行时需要 `--enable-native-access=ALL-UNNAMED`。
