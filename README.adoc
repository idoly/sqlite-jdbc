= SQLite JDBC FFM
:project-version: 3.53.2.2-SNAPSHOT

基于 JDK 25 `java.lang.foreign` 的 SQLite JDBC 4.3 驱动。Java 层继承自 https://github.com/xerial/sqlite-jdbc[xerial/sqlite-jdbc]，本地调用已改为直接访问 SQLite `sqlite3_*` C ABI，不包含 JNI 桥。

== 范围

[cols="1,1"]
|===
|项目 |本实现

|JDK
|25+

|JDBC
|4.3

|Java 包
|`io.github.idoly.sqlite`

|Maven 坐标
|`io.github.idoly:sqlite-jdbc`

|模块名
|`io.github.idoly.sqlitejdbc`

|JDBC URL
|`jdbc:sqlite:`

|本地接口
|JDK FFM
|===

本项目不兼容 xerial 的 `org.sqlite` API、旧 JDK、Android、JNI、本地 JNI 库或旧加载参数。`org.xerial:sqlite-jdbc` 与本项目不能混用。

== 构建

需要 JDK 25 和 Maven 3.9+：

[source,shell]
----
mvn clean package
----

构建只生成一个主产物：

[source,text]
----
target/sqlite-jdbc-{project-version}.jar
----

完整 JVM 测试：

[source,shell]
----
mvn test
----

GraalVM native-image 测试：

[source,shell]
----
mvn -Pnative integration-test
----

== 使用

[source,java]
----
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.ResultSet;
import java.sql.Statement;

try (Connection connection = DriverManager.getConnection("jdbc:sqlite:sample.db");
     Statement statement = connection.createStatement()) {
    statement.executeUpdate("create table if not exists app_data(id integer primary key, value text)");
    try (ResultSet rows = statement.executeQuery("select sqlite_version()")) {
        rows.next();
        System.out.println(rows.getString(1));
    }
}
----

类路径运行时允许 unnamed module 访问本地代码：

[source,shell]
----
java --enable-native-access=ALL-UNNAMED -cp "sqlite-jdbc-{project-version}.jar:app.jar" com.example.Main
----

模块路径运行时使用模块名：

[source,shell]
----
java --enable-native-access=io.github.idoly.sqlitejdbc --module-path sqlite-jdbc-{project-version}.jar:app.jar --module com.example/com.example.Main
----

== SQLite 动态库

加载顺序：

. `io.github.idoly.sqlite.ffm.lib.path` 指定的绝对路径；
. JAR 中 `io/github/idoly/sqlite/native/<OS>/<架构>/` 的库；
. 系统 SQLite 动态库。

[source,shell]
----
java --enable-native-access=ALL-UNNAMED \
  -Dio.github.idoly.sqlite.ffm.lib.path=/opt/sqlite/lib/libsqlite3.so \
  -cp "sqlite-jdbc-{project-version}.jar:app.jar" com.example.Main
----

自定义库必须匹配进程架构并导出驱动使用的 `sqlite3_*` API。Linux 默认查找 `libsqlite3.so.0`，macOS 查找 `libsqlite3.dylib`，Windows 查找 `sqlite3`。

仓库原生库构建：

[source,shell]
----
make native
make native-all
----

== 能力

支持连接、事务、Statement、PreparedStatement、ResultSet、元数据、连接池、backup/restore、serialize/deserialize、Function、Collation、BusyHandler、ProgressHandler 和更新/提交/回滚 hook。SQLite SQL 与 PRAGMA 能力由实际加载的 SQLite 版本决定。

FFM callback 与连接共享 Arena；关闭连接时先注销 callback，再关闭 SQLite 连接和 Arena。应用不得在连接关闭后调用 SQLite 提供的 callback 地址。

== 安全

安全问题请通过 GitHub Security Advisory 私下报告。只加载可信 SQLite 动态库；本项目不验证外部库的签名或来源。
